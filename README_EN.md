# Recursive Self-Improvement (RSI): A 2026 Research Map

This repository contains a Chinese-language, citation-rich overview of recursive self-improvement in foundation models, agent software, evaluation, and automated AI research. It distinguishes output refinement, persistent learning, bounded automated R&D, recursive improvement of the improver, and theoretical strong RSI.

The primary document is [README.md](README.md). Sources were verified through **2026-11-22**, with publication status labeled as peer-reviewed, technical report, project, or preprint.

Highlights include 2026 work from ICLR, ICML, COLM, EACL, Nature, Anthropic, OpenAI, Google DeepMind, Stanford HAI, Microsoft Research, Google Research, and METR.
